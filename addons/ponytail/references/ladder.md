# The ladder

Stop at the **first** rung that holds. Climb only after reading the task and tracing the real flow.

| # | Rung | Meaning |
|---|---|---|
| 1 | **YAGNI** | Do not build what was not asked |
| 2 | **Reuse** | Existing helper / pattern in this repo |
| 3 | **Stdlib** | Language standard library |
| 4 | **Platform** | Framework/runtime already chosen by the project |
| 5 | **Installed dependency** | Already in the lockfile — never add a package without asking |
| 6 | **One line** | Smallest local change that works |
| 7 | **Minimum code** | Fewest lines/files that satisfy acceptance — then stop |

If rung N fails, try N+1. Do not jump to abstractions or new frameworks for comfort.
