# Adaptive timing

Adaptive timing is an optional planning aid for uncertain, background, or
previously stuck work. It is not required before role dispatch.

When useful, estimate setup, work, validation, and handoff from comparable
evidence. Prefer splitting work that cannot produce a useful checkpoint before a
reasonable deadline.

The watchdog may enforce a deadline for a real background command. Its machine
status supports the Lead's handoff reconciliation; it does not create a second
workflow authority, retry automatically, select another model, or approve
completion.

Ordinary bounded role work proceeds without timing profiles, admission labels,
sample thresholds, or timing receipts.
