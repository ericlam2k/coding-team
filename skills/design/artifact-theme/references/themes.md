# Artifact Themes

Use these original fallback themes only when no project brand, `DESIGN.md`, or supplied template governs the artifact. Use system fonts as listed; do not fetch fonts or assets.

## Ledger Blue

Use for neutral executive reports, operating reviews, and general stakeholder decks.

- Background: `#F7F9FC`
- Surface: `#FFFFFF`
- Primary text: `#172033`
- Secondary text: `#53627A`
- Accent: `#2457A6`
- Text on accent: `#FFFFFF`
- Rule: `#CBD5E1`
- Sans: `Inter, ui-sans-serif, system-ui, -apple-system, "Segoe UI", Arial, sans-serif`
- Serif: `Georgia, "Times New Roman", serif`
- Readability: Use primary or secondary text on background and surface. Reserve accent for headings, rules, and large fills with white text.

## Moss Paper

Use for research, sustainability, planning, and reflective long-form material.

- Background: `#F5F7F2`
- Surface: `#FFFFFF`
- Primary text: `#1E2922`
- Secondary text: `#536157`
- Accent: `#35634A`
- Text on accent: `#FFFFFF`
- Rule: `#CAD3C8`
- Sans: `Aptos, Calibri, ui-sans-serif, system-ui, Arial, sans-serif`
- Serif: `Charter, Georgia, "Times New Roman", serif`
- Readability: Keep body copy dark on pale surfaces. Use pale green only as a background cue paired with a text label or icon.

## Ember Brief

Use for decisions, launches, concise proposals, and artifacts needing measured urgency.

- Background: `#FFF8F2`
- Surface: `#FFFFFF`
- Primary text: `#2E201A`
- Secondary text: `#68564D`
- Accent: `#9A3F1E`
- Text on accent: `#FFFFFF`
- Rule: `#E4CFC2`
- Sans: `Aptos, Calibri, ui-sans-serif, system-ui, Arial, sans-serif`
- Serif: `Georgia, "Times New Roman", serif`
- Readability: Limit orange to emphasis and section anchors. Pair status colors with explicit labels, never color alone.

## Slate Signal

Use for technical reviews, incident summaries, and data-heavy operational artifacts.

- Background: `#F6F7F8`
- Surface: `#FFFFFF`
- Primary text: `#20242B`
- Secondary text: `#5A616B`
- Accent: `#414B5A`
- Text on accent: `#FFFFFF`
- Rule: `#CDD2D8`
- Sans: `ui-sans-serif, system-ui, -apple-system, "Segoe UI", Arial, sans-serif`
- Mono: `ui-monospace, "SFMono-Regular", Consolas, "Liberation Mono", monospace`
- Readability: Use monospace only for identifiers or code. Distinguish chart series with labels, line styles, or markers as well as color.
